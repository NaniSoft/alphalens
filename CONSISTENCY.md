# CONSISTENCY.md — the cross-repository law, and where each of it is enforced

This file used to be a mirror of one document across five repositories, differing in
one line, holding forty-one clauses of prose. It was replaced because a clause earns
a gate when its violation is silent, and a mirror in four repositories cannot fail:
the two sites that mattered had already drifted into three implementations of one
rule, and one of the three rules was false.

So the law is the failure message of a check, and the checks live where they can run.
There is no version line in this file: **the pinned package is the version**, and
`scripts/check-antd.mjs` fails if either pin is a range.

| The law | Where it is enforced here | What it stops |
| --- | --- | --- |
| No trace of the retired component library | `scripts/check-antd.mjs` | A dependency line, an import, the generated variablesheet, its generator, the old theming symbols, or a living instruction coming back. The lockfile is read as a dependency graph, because deleting a dependency line does not empty a lockfile while another package declares the library. |
| A site stylesheet does not own a surface the design system owns | `scripts/check-stylesheet-ownership.mjs`, `test/focus-indicator.test.ts` | An unlayered bare-element declaration of the page ground, the body ink, a focus outline or a hairline colour, and any `:focus` rule at all. The cascade layer is not the cause of those failures; it is the reason they were invisible. The focus case is the one that was live here, and it is measured in the script's header. |
| A CSS-authored hidden state is escapable, and its exit is not a clock | `scripts/check-hidden-state.mjs`, `test/no-scripting.test.tsx` | A reader with scripting off receiving `opacity: 0` and no way out of it. The arming attribute has one writer, the module withdraws it on every path, and an inlined `load` listener covers the reader whose scripting started and stopped. A gate that only read the stylesheet would pass a site that renders nothing, and a test that only rendered would pass a sheet that hides nothing, so both exist. |
| Every internal destination resolves, and every fragment names an element that exists | `scripts/check-links.mjs` | A link that renders, looks right, and goes nowhere. Off-site hosts are listed, not resolved. |
| Every published document has a route, and every exception is written down | `scripts/check-routes.mjs` | A published document that no address reaches, and a later reader who "fixes" it. This repository has exactly one such document and the reason is in that script. |
| Content tests read from disk | `test/honesty.test.ts` | A content contract that passes because a compile-time macro made a loader importable. fumadocs' `defineCollections` is expanded by the bundler only, so the loaders cannot run under this runner. |
| A market-shaped surface carries a disclosure | `test/honesty.test.ts` | The failure the old gate could not see. The gate read prose and the dishonesty was arithmetic: a curve of open interest generated by a sine hash under a label reading as a live feed, with the word "illustrative" in nine-point type underneath. The surface is cut, and the gate now requires a disclosure beside anything shaped like market data rather than looking for an overclaim in the words. |
| A documentation section is a label, never a control | `lib/to-prism-tree.ts`, `test/docs-nav.test.ts` | A group rendered as an anchor with no destination, which is a control a reader can focus and not follow. The honesty status stays as words inside the section's own title; no badge, no count, no collapse, because each would tell a reader that sections describing a pipeline are independent topics to be visited in any order. |
| The rebuild changed the rendering layer and not the content | `scripts/check-content-parity.mjs` with `scripts/content-parity-expectations.json` | A copy edit during a migration. The baseline is cut before the first edit, lives outside the repository, and is destroyed at the close of the sweep; the permanent gate that outlives it is `check-links.mjs`. |
| In-development is described in the present tense of design | `test/honesty.test.ts`, plus a review convention for the rest | A shipped feature described as live. The honesty gate reads prose, so on its own it cannot see a dishonest data source; what it can now do is require that anything shaped like data carry a disclosure, and that is the part of the class the gate reaches. |

## What is not here any more, and why

- **A pinned Prism line as a contract.** The pins are in `package.json`, exact, and the
  gate fails a range. That is the whole clause. The two pins are deliberately different
  numbers: `prism-ui` requires `prism-tokens` at an exact version, so the pair states
  two facts and the gate reads both.
- **A client boundary for shared components.** The design system's items are server
  components, so there is nothing to cross and no file that exists only to cross it.
  The one client component this site has left is `components/RevealRoot.tsx`, and it
  exists to add a class and to be able to withdraw the hidden state's arming.
- **A baked variable ruleset and a pre-paint class swap.** The theme is two attributes
  on the document element and a blocking script the design system ships.
- **A canvas re-theme law.** The canvas is cut. It read computed colours from one
  element, and a resolved value does not move when the pack beneath it does, so a
  light-mode reader was served dark-mode ink until hydration. The token-driven inline
  replacement that took its place resolves through the cascade, holds every pack, and
  ships no client code.
- **Parity-locked shell styles.** The shell moved into the design system, so the
  selectors that four repositories copied by hand match nothing and are deleted. The
  `prism-docs-shell__*` and `prism-blog-layout__*` rules that sat in this sheet are gone
  for that reason, and the one that styled an anchor-with-no-href back into a label is
  gone because a group with no index is a `span` now and never an anchor.
- **A prose law about typefaces.** The typeface is loaded through `next/font/google`
  as Inter and applied as `--font-sans`, because the design system's emitted sheet names
  `Inter` in that token and ships no font file. Naming a family is not shipping it. A
  consumer must supply the file the token already names and repeat the design system's
  fallback list verbatim behind it.

## The other three sites

`landing-page` moved first and is the template. What it handed this repository, in the
order the checks name it:

1. A consumer cannot write a Prism utility class. The emitted stylesheet contains a
   utility only if a Prism component uses it, so a site's own layout goes in the site's
   own sheet, as a class.
2. The stylesheet-ownership gate is one program, copied rather than rewritten, so the
   repositories cannot disagree about what "competes" means. The list of properties and
   the two selector shapes are the same in each.
3. The published JavaScript is not loadable by Node's ESM resolver, so a site whose
   tests render a catalogue item has to inline the package in its test runner. That is
   recorded as a defect against the design system, not as a practice.
